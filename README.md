# 太阳能光伏计算器（Windows 计算程序）

按教材《2.2 太阳与地球》给出的公式，计算任意纬度、日期、时刻、光伏板倾角与方位角下的
**太阳赤纬角、时角、太阳高度角、太阳方位角、日照时间、太阳入射角**。

---

## 一、运行

直接双击运行：

```
bin\SolarCalculator.exe
```

* 无需安装：程序编译为单个 44 KB 的 `.exe`，依赖 Windows 10/11 自带的 .NET Framework 4.8。
* 若需重新编译：在项目目录执行
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\build.ps1 -Test
  ```
  （使用系统自带的 `csc.exe`，**不需要**安装 Visual Studio 或 .NET SDK。）

---

## 二、界面与操作

界面分三块：左侧 **输入参数**，右侧 **结果区**（三个标签页），底部 **按钮栏**。

### 输入参数

| 参数 | 说明 |
|---|---|
| 常用城市 | 快捷填入纬度/经度/时区，选“（自定义）”可手工输入 |
| 纬度 φ | 北纬为正（+），南纬为负（−） |
| 经度 λ | 东经为正（+），西经为负（−）；用于时刻基准换算 |
| 时区 | 北京时间 = UTC+8 |
| 日期 | 序日 n 由日期自动确定（1月1日为 n=1） |
| 时刻 | 输入的时刻，精确到秒 |
| 时刻基准 | **真太阳时（教材基准）** / 地方平太阳时 / 标准时（北京时间） |
| 光伏板倾角 β | 0° = 水平，90° = 垂直 |
| 光伏板方位角 γ | 0° = 正南，向西为正（+），向东为负（−） |

> **默认“真太阳时”**，此时程序与教材例题完全一致，不引入任何附加修正。

### 结果区

* **计算结果**：顶部 12 个结果速览磁贴，下方为**逐式代入的完整计算书**
  （列出 δ、τ、h、γs、τ0、T、θ 每一步的数值代入过程，可直接与教材例题对照）。
* **日照曲线**：全天 0–24 h 的 **太阳高度角 h** 与 **太阳入射角 θ** 曲线，
  含白昼底色、日出/日没竖线、当前时刻标记。
* **公式说明**：全部公式与符号约定，含下文的重要勘误。

### 按钮

* `计 算 (F5)` —— 重新计算
* `复制结果` —— 把计算书复制到剪贴板
* `保存为 txt` —— 导出计算书（UTF-8 带 BOM，记事本可直接打开）
* `恢复默认` —— 恢复预置参数

## 三、采用的公式

设 φ 为纬度，δ 为赤纬角，τ 为时角，h 为太阳高度角，γs 为太阳方位角，
n 为序日，β 为光伏板倾角，γ 为光伏板方位角，θ 为太阳入射角。角度单位均为度。

| 量 | 公式 |
|---|---|
| 序日 | n = 日期在当年中的序号（1月1日为 1） |
| **太阳赤纬角** | δ = 23.45° · sin[ 360° × (284 + n) / 365 ] |
| **时角** | τ = 15° × ( 真太阳时 − 12 ) |
| **太阳高度角** | sin h = sinφ · sinδ + cosφ · cosδ · cosτ 　（式 2-3） |
| 正午高度角 | h午 = 90° − \|φ − δ\| |
| 天顶角 | θz = 90° − h |
| **太阳方位角** | cos γs = ( sin h · sinφ − sinδ ) / ( cos h · cosφ ) 　（式 2-7）<br>sin γs = cosδ · sinτ / cos h 　（式 2-8） |
| **日出/日没时角** | cos τ0 = − tanφ · tanδ 　（式 2-9）<br>τ0出 = −arccos(−tanφ tanδ)，　τ0没 = +arccos(−tanφ tanδ) |
| **日照时间** | T = (2/15°) · arccos( − tanφ · tanδ ) = 2·\|τ0\| / 15° 　（式 1-11） |
| 日出/日没时刻 | 日出 = 12 − T/2，　日没 = 12 + T/2（真太阳时） |
| **太阳入射角** | cos θ = sinδ ( sinφ cosβ − cosφ sinβ cosγ )<br>　　　 + cosδ cosτ ( cosφ cosβ + **sinφ sinβ cosγ** )<br>　　　 + cosδ sinβ sinγ sinτ |

方位角约定：自**正南**起算，**向西为正、向东为负**，范围 ±180°，与教材一致。
当 \|−tanφ tanδ\| ≥ 1 时自动判定为**极昼**（T = 24 h）或**极夜**（T = 0 h）。

## 四、⚠ 课件式 (2-13) 有一处笔误（重要）

课件中太阳入射角公式写作：

```
cosθ = sinδ( sinφcosβ − cosφsinβcosγ )
     + cosδcosτ( cosφcosβ + sinφsinβ )        ← 此处漏写了 cosγ
     + cosδsinβsinγsinτ
```

第二括号内的 `sinφsinβ` **漏乘了 `cosγ`**。按原文计算会得到**物理上不可能**的结果：

* **反例 1**：北京（φ=39.90°）12月22日 10:30，β = 60°，γ = −30°
  → 原文得 cosθ = **1.0493**（余弦值不可能大于 1）。
* **反例 2**：上海（φ=31.12°）9月22日正午，竖直朝北的光伏板（β = 90°，γ = 180°）
  —— 此时太阳在正南、高度角 58.27°，几何上 θ 必为 121.73°，
  而原文给出 **59.49°**。

本程序采用**补回 cosγ 的正确形式**，即国际通用的
Duffie & Beckman《Solar Engineering of Thermal Processes》式 (1.6.2)：

```
cosθ = sinδ( sinφcosβ − cosφsinβcosγ )
     + cosδcosτ( cosφcosβ + sinφsinβcosγ )
     + cosδsinβsinγsinτ
```

> 由于 γ = 0° 或 180° 时 cosγ = ±1，若你的例题中光伏板都朝正南（γ = 0°），
> 两种写法结果相同，**教材例题不受影响**；只有当 γ 取一般角度时才必须使用修正式。
> 程序中其他公式（2-3、2-7、2-8、2-9、1-11）与课件完全一致，未作任何改动。

## 七、时刻基准换算（可选功能）

教材例题采用**真太阳时**。若你手上是钟表时间，程序提供换算：

```
经度修正 = 4 min/° × ( λ − 15°/h × 时区 )
均时差   EoT = 9.87 sin(2B) − 7.53 cos B − 1.5 sin B,  B = 360°(n − 81)/364   （min）
真太阳时 = 输入时刻 + ( 经度修正 + EoT ) / 60
```

* 选 **地方平太阳时** → 只作均时差修正
* 选 **标准时（北京时间）** → 经度修正 + 均时差修正

> 说明：均时差采用工程常用近似式，与天文年历精确值可有约 0.5 min 差异。
> 若要与教材例题严格对齐，请保持默认的“真太阳时”。
